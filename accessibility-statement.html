Accessibility Statement

Last updated: 6 November 2026.

This Accessibility Statement is issued by Russell Hinderman, trading as DevHinderman2026 (the "Developer"), in respect of Endless Labyrinth: this website, the game it plays, and the Windows version of the game. It sets out the Developer's commitment to accessibility, the measures by which that commitment is given effect, the devices and assistive technologies that are supported, the limitations that are known, and the means by which a problem may be reported.

1. Commitment

Endless Labyrinth is an audio game, created by a developer who is totally blind and who tests it by ear. The Developer is committed to ensuring that the game and this website are fully playable and readable by blind and low-vision players, without sight, on every device that the web version supports. Accessibility is not an addition to the design of Endless Labyrinth; it is the design.

2. How the game is played

All of the information that a player requires is conveyed by sound: the position of each object, its distance, and whether it lies in front of or behind the player. The game speaks for itself, using the voice built into the player's device. For that reason it asks the player to turn your screen reader off while you play and to turn it on again on leaving, and it states the relevant shortcut at the start of every session. On a phone or tablet the game is played with touch gestures; on a Chromebook, Mac or Linux computer, with the keyboard. Every gesture and key is documented in About and how to play.

3. Supported screen readers

The website is designed to be read with the screen reader built into the player's device: VoiceOver on an iPhone, iPad or Mac, TalkBack on Android, ChromeVox on a Chromebook, and Orca on Linux. The Accessibility page identifies the appropriate screen reader for the device in use and provides a set-up guide for each.

4. Measures taken on the website

The website is built in accordance with the following principles:

  1. every page uses genuine headings, so that sections may be navigated by heading, and genuine lists, links and buttons;
  2. the site links are identical on every page; on a narrow screen they are placed behind a button named Site links menu, which announces whether it is expanded or collapsed;
  3. no function depends on colour, images or the use of a mouse; every control operates from the keyboard and with a screen reader;
  4. status messages, such as the result of a backup or the checking of events, are announced as they appear, by means of live regions; the notice of a Windows update on the home page is placed at the top of the page in a region named Alert, which is listed among the page's landmarks and never interrupts the screen reader;
  5. event descriptions are written for the keyboard and are reworded with gestures on a phone, so that instructions always correspond to the device in use;
  6. the display options on the Accessibility page provide high contrast and bigger text for low-vision players, applied on every page and within the game.

5. Supported devices and known limitations

  1. Phones and tablets: iPhone and iPad (iOS 18.4 or later) and Android phones and tablets with a current version of Chrome.
  2. Computers: Chromebook, Mac and Linux, with the keyboard. Chrome, Edge and Safari are the browsers with which the game is tested; Firefox is expected to work but is not tested.
  3. Windows computers are pointed to the Windows version of the game, which is described in section 6.
  4. There is no Braille output during play, because the screen reader is turned off while the game is played.
  5. On an iPhone or iPad, silent mode mutes the game's sounds while its voice continues to speak; the game therefore asks that silent mode be turned off.

6. The Windows version

The Windows version of Endless Labyrinth supports the NVDA and JAWS screen readers and Braille displays, and presents everything that it speaks in Braille when a Braille display or a Braille notetaker is in use. Its help, which is opened with the H key, describes every mode, every key and every sound, with demonstrations that may be played. From version 2.0.0 the Windows version can update itself at the player's request, by means of Check for Updates on the main menu, so that a blind player is not required to navigate a download page, extract an archive and transfer a saved-data folder in order to obtain a new version; the player confirms each update with a single key, and saved scores and settings are retained.

7. Feedback and reporting a problem

If any part of this website or of the game does not function with your screen reader, Braille display or other assistive technology, the Developer asks that you report it at the contact address given in the footer of every page. Problems reported by players are corrected in the next version and recorded in the Update History.
